 Oportuniza: Assistente Virtual de Carreira Tech

Oportuniza é uma plataforma concebida durante o Kick-Off da Residência Tecnológica do programa Embarque Digital (Porto Digital). Nossa missão é quebrar o "muro invisível" que afasta jovens da periferia do seu primeiro emprego na área de tecnologia, transformando a rejeição silenciosa em direcionamento acionável.

 O Problema

Jovens de periferia buscando inserção no mercado tech esbarram em três grandes barreiras:

O Limbo do RH: Plataformas tradicionais reprovam candidatos por algoritmos, sem fornecer feedback estruturado.

Linguagem Excludente: Vagas com jargões corporativos em inglês (framework, squads, mindset) geram autoexclusão.

Golpes e Fraudes: O desespero por renda empurra jovens para grupos de WhatsApp informais, onde sofrem phishing com vagas falsas.

 A Solução

O Oportuniza atua como um Assistente Virtual de Carreira Tech (Hub Agregador). Focado 100% no candidato, o aplicativo não apenas lista vagas, mas atua como um mentor, preparando o jovem para a contratação através do nosso inovador Filtro de Proatividade.

Principais Funcionalidades

 Letramento Visual via IA: Tradução de descrições corporativas complexas para uma linguagem simples e acessível.

 Termômetro de Match (%): Cruzamento em tempo real do perfil do jovem com os requisitos da vaga.

 Feedback Estruturado (RH do Candidato): Diagnóstico claro mostrando pontos fortes e apontando exatamente qual habilidade falta.

 Ponte para Qualificação (Badges): Indicação direta do curso gratuito exato (ex: DIO, Fundação Bradesco) que preenche a lacuna do perfil. Ao concluir, o jovem recebe um Selo de Competência (Badge), aumentando seu Match para 100%.

 Selo Vaga Verificada: Curadoria anti-golpes, garantindo que todas as vagas listadas são seguras.

 Arquitetura e Engenharia de Produto

Este repositório documenta a fase de concepção, pesquisa e modelagem do produto. A arquitetura idealizada para o MVP baseia-se em:

Frontend (Proposto): WebApp Mobile-First (HTML, CSS, JS/React).

Backend & Automação: Orquestração de fluxos via n8n.

Integração de IA: Consumo de APIs de LLM (ex: Gemini/OpenAI) com prompts restritos para Letramento Visual e Cálculo de Match (Temperatura 0.1).

Mensageria: Integração com WhatsApp Business API para alertas de prazos.
